# Veda Technology Business & Services Website

A professional and responsive business website created for a technology and digital-services organization such as Veda Technology.

The website presents technology programs, training, internship opportunities, IT and digital services, company information, FAQs, and contact information.

---

## 📌 Project Overview

The **Veda Technology Business & Services Website** is a modern multi-section website designed to provide visitors with clear information about technology programs, services, training, internships, and the organization.

The project focuses on:

- Professional UI design
- Responsive web design
- Reusable components
- JavaScript interactions
- Mobile-friendly navigation
- Basic SEO practices
- Git and GitHub workflow

---

## 🎯 Project Objectives

The main objectives of this project are:

1. Create a professional technology-business website.
2. Build a responsive layout for desktop, tablet, and mobile.
3. Create reusable cards for services and programs.
4. Add JavaScript-based interactions.
5. Implement an FAQ section.
6. Apply basic SEO principles.
7. Practice Git and GitHub.
8. Deploy the project using a public repository.

---

## 🛠️ Technologies Used

- HTML5

- JavaScript
- Responsive Web Design
- Git
